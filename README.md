# 部署図鑑マップ

瓜生山学園の部署を「どこにあるか」「何を相談できるか」から探せる、1ページの案内ツールです。
公式キャンパスマップ（鳥瞰図・案内図）と部署マスタを重ねて、**建物から** と **相談内容から** の
2通りで目的の窓口にたどりつけます。

👉 公開URL: https://<ユーザー名>.github.io/<リポジトリ名>/

## できること

- **建物から探す** — 7棟それぞれの階層案内。階ごとに入っている部署が並び、クリックで窓口の詳細（電話・メール・受付時間・相談例）が開きます。
- **相談内容から探す** — 「履修・成績」「支払い・予算」「アカウント・システム」など28トピックを5カテゴリに整理。相談先の部署・場所・連絡先がその場で出ます。
- **検索** — 部署名だけでなく相談キーワードも対象。全角/半角・中黒・スペースの違いは無視して照合します（例: `Googleアカウント` `予算執行票` `休学・退学`）。
- **地図の切り替え** — 公式鳥瞰図と公式案内図を切り替え、選んだ建物の位置に自動でフォーカス。右パネルは「›」で畳めます（幅1180px以下では本文の下に移動）。
- **文字サイズ切替** — ヘッダーの「文字 大」で全体を拡大（説明会での投影用）。

## 更新のしかた

部署・人数・連絡先の修正は **`campus-data-2.js` の該当箇所を書き換えるだけ** です。画面側の変更は不要です。

```js
// 部署を1件直す
{"division":"法人事務局","name":"経理課","count":6,
 "location":"望天館 2階","building":"bt","floor":"2階",
 "keywords":["予算","支払い", ...]}

// 連絡先を足す
window.CAMPUS.contacts = {
  "DX推進課": { window:"情報システム室", place:"人間館 B1F", tel:"…", hours:"…" }
}
```

- `umbrella: true` を付けた部署は個別カードを出さず、建物ヘッダーの組織チップに人数だけ合算されます（○○事務局のように複数部署の集合体を1枠にしないための指定）。
- 地図上の位置は `buildings` の `pos`（鳥瞰図）と `pos2`（案内図）で、画像左上を0、右下を100とした%座標です。
- 相談トピックは `topics` の配列。`depts` に部署名を並べると相談先として表示されます。

## 公開設定（GitHub Pages）

リポジトリの **Settings → Pages** で Source を `main` ブランチの `/docs` フォルダに設定します。数分後に上記URLで公開されます。

## 注意

- 個人名・個人の連絡先は含めていません。掲載しているのは部署単位の公開窓口情報のみです。
- 受付時間は2024年度学修ガイド時点のものです。年度替わりに確認してください。
- Webフォント（Google Fonts）を参照するため、表示にはインターネット接続が必要です。完全オフラインで配布する場合は単一ファイル版を使ってください。
